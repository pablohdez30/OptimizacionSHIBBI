==========================================
   SHIBBISHOP MANAGER - Instrucciones
==========================================

OPCIÓN 1: Usar el .exe (recomendado)
-------------------------------------
1. Doble clic en "ShibbiShop Manager.exe"
2. Listo! La app se abre directamente.

Primera vez:
- Ve a Configuración y revisa los datos de la empresa.
- Configura la ruta donde quieres guardar los documentos.
- Si ya tenías facturas/presupuestos, pon el último número usado.


OPCIÓN 2: Desde terminal (si tienes Python)
--------------------------------------------
1. Abre una terminal (CMD o PowerShell)
2. Navega a la carpeta del proyecto:
   cd C:\ruta\al\proyecto\OptimizacionSHIBBI
3. Instala dependencias (solo la primera vez):
   pip install -r requirements.txt
4. Ejecuta:
   python main.py


GENERAR EL .EXE
--------------------------------------------
Si necesitas regenerar el .exe:
1. Abre terminal en la carpeta del proyecto
2. Ejecuta:
   python build_exe.py
3. El .exe se genera en la carpeta "dist/"


ESTRUCTURA DE ARCHIVOS
--------------------------------------------
ShibbiShop Manager.exe    <- La aplicación
PresupuestoPlantilla.xlsx <- Plantilla de presupuestos (necesaria)
data/shibbishop.db        <- Base de datos (se crea sola)

Los documentos se guardan en:
{Ruta configurada}/CAESPAN 2026/
    FACTURAS/       <- Facturas (PDF + Excel)
    PRESUPUESTOS/   <- Presupuestos (PDF + Excel)
    DESGLOSES/      <- Desgloses de costes (Excel)
